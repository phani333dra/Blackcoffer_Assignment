Project Objective

The main objective of the project was to fetch or retrieve the data from an API source to Power BI.

Project Description

The client has provided the url of three API i.e. Login API and data source API.

We have to get the authentication from the first URL for the access of the rest two urls and get data back and make a report for their Ratings data.

Our Solution

We built a Power BI app which cask the user for ID/Pswd and returns the Users and Declaration table.

We have coded this in M Language which asks the access token from Login API and provides that token to user data API and declaration data API and get the data table back from these API.
